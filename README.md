## 🏛 Авторский манифест

> **ApexMotion** спроектирован как исчерпывающий визуальный полигон, креативная среда и инструмент для глубокого исследования веб-анимаций, графических конвейеров и вычислительной геометрии наяву.
>
> Проект создан **Стариковым Дмитрием Сергеевичем** в 2026 году. Главная цель — дать frontend-инженерам и творческим разработчикам не абстрактные макеты, а прозрачный исполняемый математический код: от уравнений Навье-Стокса и квантования по матрице Байера до SDF-полей, генераторов кривых Безье и процедурного звука.

## 🚀 Что нового в версии 5.0 (Full Production Upgrade)

- ⚡ **Motion Generators Suite**: 4 встроенных интерактивных генератора (CSS Keyframes, визуальный Cubic Bezier, Particle FX Studio и WebGL GLSL Shader Playground).
- ⌘ **Command Palette (`Ctrl+K` / `Cmd+K`)**: быстрый поиск по всем 998 эффектам каталога, навигация по разделам и переключение тем.
- 🗂 **User Workspace**: личная коллекция избранного, история запусков, экспорт и импорт состояния в JSON через `localStorage`.
- 🔗 **Deep-Linking & Hash Routing**: поддержка постоянных ссылок на любой эффект вида `#effect/42` с кнопкой «Поделиться ссылкой».
- 🛡 **Isolated Sandbox Playground 2.0**: безопасное исполнение пользовательского JavaScript внутри `<iframe sandbox="allow-scripts">` с перехватом `console.log` и ошибок.
- 📊 **Performance Monitor HUD**: живой замер FPS, Frame Time (мс), статус WebGL и переключатель профилей нагрузки (Ultra 120 FPS / High / Balanced / Battery Saver).
- 🔔 **Toast Notifications**: всплывающие статусные уведомления при копировании кода, пресетов и ссылок.
- 🎨 **4 Дизайнерские темы оформления**: Dark Luxury, Deep Cyber, Monokai Minimal, Midnight Obsidian.

## ✨ Ключевые возможности платформы

### 🌌 1. 3D WebGL Particle Core (Three.js)
- Галактика из **2200 частиц** с плавной аналитической интерполяцией между 4 топологиями:
  - **Сфера Фибоначчи** (равномерное распределение на золотом угле $\phi$).
  - **Тор Клейна** (параметрическая тороидальная геометрия).
  - **Двойная спираль ДНК** (полинуклеотидный шаг с водородными связями).
  - **Интерференционная волна** (суперпозиция синусоидальных фаз).
- Реактивный параллакс по координатам курсора и тач-событиям.
- Живой HUD-счётчик FPS и времени рендеринга.

### ⚡ 2. Флагманские модули взаимодействия (Showcase)
- **3D Parallax Tilt with Glare**: кинематический расчет угла наклона карточки с динамической световой маской отражения.
- **GSAP 3 Elastic Magnetic Pull**: притяжение интерактивных триггеров к вектору курсора с затухающим гармоническим возвратом (`elastic.out`).
- **Hacker Glyph Scramble Decoder**: киберпанк-дешифратор строк со случайной генерацией матрицы символов.
- **Liquid Gooey Metaballs**: физическое слияние капель ртути на базе шейдерных фильтров `feGaussianBlur` и `feColorMatrix`.
- **Sonar Wave Radar**: процедурная интерференция звуковых волн на Canvas 2D.
- **Bi-directional Kinetic Marquee**: аппаратные бегущие строки 120 FPS с нулевой нагрузкой на CPU.

### 🎛 3. Интерактивные генераторы движения (Suite)
1. **CSS Keyframes Generator**: интерактивная настройка длительности, timing-функций, пресетов (*Pulse, 3D Float, Shimmer, Elastic, Orbit*) и экспорт чистого CSS.
2. **Cubic Bezier Curve Editor**: холст с перетаскиванием контрольных точек $P_1$ и $P_2$, пресетами (*Ease, Bounce, Expo, Linear*) и интерактивным тестовым забегом анимации.
3. **Particle FX Studio**: управление эмиттером частиц (гравитация, разлёт, размер, плотность, цветовые профили) с генерацией чистого JavaScript-кода.
4. **GLSL Fragment Shader Playground**: WebGL-редактор с компиляцией фрагментных шейдеров на лету (пресеты: Plasma, SDF Rings, Warp Tunnel, Gyroid).

### 🧪 4. Интерактивная физическая лаборатория
Полноценный симулятор взаимодействия частиц на Canvas 2D с реальными физическими параметрами:
- **Particles Count**: плотность ансамбля от 20 до 500 узлов.
- **Flow Velocity**: скорость симуляции от $0.5\times$ до $5.0\times$.
- **Gravity Field**: вектор гравитации от $-2.0G$ (антигравитация) до $+2.0G$.
- **Repel Force**: радиус и сила импульсного расталкивания при клике/тапе.
- **Node Connection Radius**: дистанция построения молекулярной паутины.
- **Particle Size**: масштабирование диаметра тел.
- **Color Profiles**: пресеты *Cyber Cyan*, *Neon Pink*, *Matrix Green*, *Solar Gold*, *Monochrome*.
- **Управление**: *Пауза / Старт*, *Импульсный взрыв*, *Сброс*, *Fullscreen*.

### 📚 5. Каталог 998 технологий & эффектов
- **100% уникальность**: 998 самостоятельных эффектов без дубликатов, циклических шаблонов или заглушек.
- **Живое превью в каждой карточке**: каждая технология снабжена персональным мини-холстом (Лиссажу, странные аттракторы, клеточные автоматы, волны Герстнера, спектрограммы).
- **GPU-оптимизация (`IntersectionObserver`)**: рендеринг активен только для видимых карточек.
- **Мгновенный поиск & Фильтры**: debounce-поиск по формулам, тегам, движкам и категориям.
- **Система избранного (`localStorage`)**: сохранение понравившихся решений в один клик.

### 💻 6. Изолированный Code Playground 2.0
- Сплит-интерфейс: редактируемый код слева, изолированный `<iframe>` sandbox справа.
- Перехват `console.log` и синтаксических ошибок в статусную консоль.
- Возможность экспорта готового автономного `.html` файла в один клик.

### 🔊 7. Процедурный Web Audio API Синтезатор
- Встроенный звуковой движок без тяжелых аудио-файлов: синтез частот (Blip, Hover, Laser, Blast) прямо через `AudioContext`.

## 🛠 Быстрый локальный запуск

Так как проект не требует тяжелых бандлеров и транспайлеров, его можно запустить любой локальной командой:

```bash
# Клонирование репозитория
git clone https://github.com/EnterPC-Core/apexmotion.git
cd apexmotion

# Запуск локального сервера (любой вариант)
python3 -m http.server 8080
# или
npx serve .
# или
php -S localhost:8080
```

Откройте в браузере: `http://localhost:8080`
